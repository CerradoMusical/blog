> 📰 Portal editorial moderno construído com Next.js, TypeScript e Tailwind CSS

## 🌟 Features Principais

✨ **Design Moderno**: Interface clean e responsiva  
📱 **Mobile-First**: Adaptação perfeita para todos os dispositivos  
🎵 **Playlists Spotify-Style**: Interface inspirada no Spotify  
🖼️ **Fotos em Destaque**: Cards com imagens grandes e impactantes  
⚡ **Performance**: Otimizado com Next.js 14  
🎨 **Tailwind CSS**: Sistema de design consistente

## 🎯 Como Usar

### Desenvolvimento Local

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/portal-editorial.git

# Instale dependências
cd portal-editorial
npm install

# Execute em desenvolvimento
npm run dev
```

### Deploy para Produção

```bash
# Build e export para GitHub Pages
npm run build

# O deploy é automático via GitHub Actions
```
